💡 가이드

🚀 30초 시작
1. 🎯 퀴즈 → 🧠 Smart Quiz 선택 → 카테고리 → 🚀 시작
2. Stage 1은 타이핑 영→한 (뜻 직접 입력) — 객관식 X, 확실한 기억 강제
3. 정답이 빠르면(Cold Correct) Stage 자동 진행 (1→2→3→4→5)
4. 📰 기사 탭에 Claude가 만든 JSON 파일 import → 비행기에서 오프라인 학습

🪜 5단계 학습 진행

  1. ✏️ Meaning Typing E→K — 영어 단어 보고 한국어 뜻 직접 입력 (객관식 X)
  2. 🧩 Fill-in-the-Blank — 예문 빈칸 채우기
  3. 📝 Dictation — TTS 듣고 영어 입력
  4. ✍️ Production K→E — 한국어 뜻만 보고 영어 입력 (가장 어려움)
  5. 🌟 Sentence Production — 내 문장 직접 만들기

⭐ Cold/Medium/Slow 평가

첫 시도 빠른 정답(Cold)만 진짜 mastery로 인정 → Stage 진행. 정답 보고 다시 맞힌 건 Recovered(승급 안 됨). 표면 정답률 90% ≠ 진짜 외운 단어 30%일 수 있음.
