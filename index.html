📚 이 노트는 뭐 하는 도구인가요?

영어 단어를 "보면 아는 단계"에서 "실제로 쓸 수 있는 단계"로 끌어올리는 학습 도구입니다. Spaced Repetition System (SRS, 간격 반복)과 5단계 학습 진행을 결합해, 매일 어떤 단어를 어떤 방식으로 복습할지 자동으로 선택해 줍니다.

기본으로 100개 단어가 들어 있고, 직접 추가/수정/삭제 가능합니다. 미국식 발음이 모든 단어/예문에 붙어 있어요.

⭐ 가장 중요한 한 가지

"틀린 직후 정답을 보고 맞히는 건 '복구 연습'이지 '외운 것'이 아니다."

그래서 이 앱은 결과를 5가지로 자동 분류합니다:
  • 🧊 Cold Correct — 첫 시도 빠른 정답 (≈10초 이내) → 진짜 외운 거, 단계 올라감
  • 🌤️ Medium Correct — 첫 시도 정답이지만 약간 느림 → 같은 간격 유지
  • 🐢 Slow Correct — 첫 시도 정답인데 25초 이상 → 한 단계 후퇴
  • ❌ First Miss — 첫 시도 실패 → 내일 다시
  • 🩹 Recovered — 정답 보고 다시 맞힘 → 단계 안 올라감, 내일 첫 시도에서 진짜 증명해야 함

🪜 5단계 학습 진행 (점진적 난이도)

각 단어는 정답이 누적되면서 다음 단계로 자동 진행됩니다. 새 단어는 Stage 1부터 시작, 정답이 빠르면 한 단계씩 올라가요.

  1. 🔍 Recognition — 영어 단어 보고 뜻 4지선다 (새 단어 진입)
  2. 🧩 Fill-in-the-Blank — 예문 빈칸 채우기 (문맥 힌트 있음)
  3. 📝 Dictation — 듣고 영어로 받아쓰기 (청각 cue 있음)
  4. ✍️ Production K→E — 한국어 뜻만 보고 영어 직접 입력 (가장 빡센 핵심 단계)
  5. 🌟 Sentence Production — 단어로 내 문장 직접 만들기 (Active vocabulary)

❓ 자주 묻는 질문

"N일 후 복습"은 자동으로 그날 출제되나요?

Smart Quiz를 "복습 임박순" 또는 학습 탭을 "복습할 단어만"으로 열면 자동 출제됩니다. "랜덤"으로 열면 SRS와 무관하게 무작위로 뽑혀요. 기본 설정이 "복습 임박순"이라서 그냥 시작 누르면 SRS가 알아서 굴러갑니다.

새 단어 추가는 어디서 하나요?

➕ 추가 탭. 단어, 발음(IPA, 선택), 뜻, 예문(줄바꿈으로 여러 개 가능), collocation(콤마 구분), 카테고리 입력. 새 단어는 Stage 1로 시작합니다.

데이터가 사라지진 않나요?

브라우저의 localStorage에 자동 저장됩니다. 다른 컴퓨터로 옮기거나 백업하려면 💾 백업 탭 → "JSON 내보내기". 파일 위치가 바뀌면 데이터가 분리될 수 있으니 정기 백업 권장.

타이핑할 때 오타로 틀렸어요. 정답 처리 안 되나요?

타이핑/받아쓰기/빈칸 퀴즈에서 틀리면 "😅 사실 맞췄어 (오타였음)" 버튼이 뜹니다. 누르면 Cold Correct로 재평가됩니다.

📖 학습 탭과 🎯 퀴즈 탭 차이가 뭐예요?

학습 탭: 카드 뒤집기 + 자기 평가 (다시/어려움/좋음/쉬움). 새 단어 익히기, 가볍게 훑기.
퀴즈 탭: 객관식·타이핑·받아쓰기 등 자동 채점 + 응답시간 측정. 진짜 실력 점검.
대부분 시간은 🎯 퀴즈 탭의 🧠 Smart Quiz를 쓰면 됩니다.

하루에 새 단어 몇 개가 좋아요?

과학적으로는 10~20개가 무난합니다. 100개 한 번에 외우려고 하면 복습 부담이 폭발해요. ➕ 추가에서 매일 조금씩 늘리는 게 효율적.

⌨️ 단축키 있나요?

학습 카드: Space = 뒤집기, 1/2/3/4 = 다시/어려움/좋음/쉬움.
퀴즈 타이핑: Enter = 제출/다음.
문장 만들기: Ctrl/Cmd+Enter = 제출.

📊 통계에서 봐야 할 것

  • 🏆 True Master — coldStreak ≥ 3 & Stage ≥ 5. 진짜 외운 단어 수.
  • ⚠️ Passive 위험 — 보면 아는데 직접 못 쓰는 단어. 가장 조심해야 할 그룹.
  • 🔁 Fragile — 자주 까먹는 단어.
  • 🧊 오늘 Cold Correct — 오늘 진짜 외운 단어 수 (표면 정답률과 분리됨).

표면 정답률 90%라도 Cold Correct 30%면 실제로는 passive vocabulary가 많은 것입니다. 정직한 지표는 Cold Correct입니다.

🧪 과학적 근거 (더 알고 싶으면)

왜 이렇게 만들었나? — 참고 연구

Roediger & Karpicke (2006, 2008) — Testing Effect: 단순 재학습보다 스스로 꺼내는 retrieval practice가 장기 기억을 더 강화한다. 그래서 객관식보다 타이핑이 강함.

Cepeda et al. (2006, 2009) — Spacing Effect: 몰아서 외우는 것보다 간격을 둔 분산 학습이 장기 회상에 유리. 단, 너무 짧거나 너무 길어도 안 됨 (nonmonotonic gap effect).

Candry et al. (2020), Li (2022) — L2 어휘 학습에서 retrieval practice가 단순 반복보다 효과적.

First-Attempt Mastery Rule — Karpicke의 desirable difficulty 개념을 따라, 같은 세션에서 정답을 본 직후 다시 맞히는 건 short-term recovery이지 spaced retrieval success가 아니므로 SRS 승급에서 제외.
